# Season index banners

Small cards on **Expansions & Seasons** (`/expansions`), right column.

Same specs as RAD Loot / expansion index banners (**140 px** tall on screen).

| | |
|---|---|
| **Path** | `public/images/seasons/activities/{slug}.webp` |
| **Recommended size** | **480 × 140 px** |
| **Alternative** | **960 × 280 px** Retina, or **1400 × 350 px** (4 : 1) with key art on the left |
| **Format** | WebP or JPG, sRGB |

Images use `object-cover` anchored to the **left**. Missing files show a plain placeholder with “Coming soon”.
