# Pantheon boss art

One image per Pantheon boss, used for the weekly featured bosses (home "This week" tile, split in two halves, and the weekly reset share image).

- **Size:** 1280 × 720 px (16:9), WebP or JPG (any size ≥ 1280 px wide is fine; it gets converted).
- **Framing:** keep the boss in the middle third — each half of the home tile crops the image to a narrow, taller shape.
- Missing files fall back to the generic Pantheon art.
